# MeetLens Customer Value

## Primary wedge
Technical architecture and design-review meetings for software and fintech teams.

## Problem
A meeting with many participants produces more questions than a moderator can fairly evaluate in real time. Raw frequency favors repeated popular topics and can suppress minority or expert information needs.

## MeetLens value hypothesis
MeetLens compresses semantically redundant questions into intent-level categories, produces distinct nominee questions, ranks them using explainable signals, and lets a human moderator select the final questions.

## Measurable outcomes
- lower semantic redundancy
- fewer questions requiring manual triage
- broader participant/perspective coverage
- faster moderator decisions
- higher usefulness of the final asked-question set

## What remains unproven
All current results are controlled/synthetic. External human evaluation is required before claiming customer value.
