# Evidence Plan

## Evidence ladder
E0 concept
E1 working software (current baseline)
E2 synthetic benchmark (current sanity check)
E3 controlled pilot (next target)
E4 repeatable user validation
E5 measurable business value
E6 scalable product evidence

## E3 exit criteria
- at least 3 real meetings in the target wedge
- >= 30 participant questions across the meetings
- >= 60% moderator acceptance among proposed nominees
- measured reduction in manual triage time versus a baseline process
- no critical privacy/security incident
- every moderator decision traceable to an audit event

Targets are pilot hypotheses, not guaranteed outcomes.

## Evidence generated per meeting
- raw question count
- intent count
- duplicate suppression
- nominee count
- moderator actions
- participant coverage
- outcome distribution
- usefulness ratings where captured
- model/prompt/fallback metadata
