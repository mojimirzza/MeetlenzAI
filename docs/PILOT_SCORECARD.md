# MeetLens — Pilot Scorecard

## Pre-pilot gate
Core application runtime: PASS
Core tests: PASS
Controlled semantic benchmark: PASS
Customer validation: NOT YET RUN

## Required external meetings
Minimum: 3

For every meeting record:

| Field | Required |
|---|---|
| Meeting type | yes |
| Participant count | yes |
| Raw questions | yes |
| Intents | yes |
| Compression rate | yes |
| Nominees | yes |
| Moderator accepts | yes |
| Moderator edits | yes |
| Moderator rejects | yes |
| Triage time | yes |
| Questions asked | yes |
| Outcomes | yes |
| Usefulness rating | where feasible |
| Model/prompt version | yes |

## Pilot success gate
Proceed to major production hardening only if the three-meeting sample shows:

- consistent moderator trust in nominees;
- measurable reduction in manual triage effort;
- no material loss of important participant perspectives;
- no critical privacy/security incident;
- sufficient evidence to justify continued product development.

No numeric target is claimed as a market benchmark until external data exists.
