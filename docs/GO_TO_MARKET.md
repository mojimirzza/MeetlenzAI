# Go-to-Market Pilot

## First wedge
Technical architecture/design reviews at software and fintech organizations.

## Pilot offer
A privacy-first, local-first question intelligence layer that can be run alongside an existing meeting workflow without replacing the meeting platform.

## Buyer pitch
Reduce moderator triage work, prevent duplicate questions from consuming meeting time, and make participant information needs visible without letting popularity become the decision rule.

## Pilot package
- 3 guided meetings
- setup and privacy policy workshop
- meeting evidence report after every session
- baseline-vs-MeetLens comparison
- moderator debrief

## What to learn
- Does semantic compression save time?
- Does the moderator trust the nominees?
- Which priority signals correlate with actual usefulness?
- How much identity/visibility control do customers require?
- Which vertical-specific language causes clustering errors?
